# Use physical demonstration pages

The repository's `public/` directory is the Nginx document root; repository documentation, tests, and Git metadata remain outside the served tree. Each Available Demonstration will have its own directory at that site root, with an `index.html` entry page and its demonstration-specific material stored alongside it. Its canonical URL includes a trailing slash, such as `/quickSort/`; Nginx will use normal directory indexes and 404 handling rather than routing all demonstration URLs through a single-page application fallback. Demonstration-specific source, frame data, rendering code, styles, and media belong in that directory, while the common player, layout, fonts, and locally hosted third-party libraries belong in `/assets/`. This duplicates a small entry page per demonstration but makes the deployed structure and URL-to-file mapping explicit without duplicating shared runtime code.

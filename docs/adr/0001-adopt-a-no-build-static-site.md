# Adopt a no-build static site

The site will be served directly by Nginx without a Node, npm, or Webpack build step. Vue and jQuery will be removed in favor of browser-native HTML, CSS, and JavaScript. D3, Ace, `clone`, and `d3-transform` remain because the demonstrations use them and will be hosted locally; jquery.popdown, Lodash, and string-format will be removed because the migrated runtime does not need them. This keeps deployment self-contained without expanding the migration into rewrites of established visualization and editor functionality. The site targets maintained versions of Chrome, Edge, Firefox, and Safari, so its source may use native ES Modules, `fetch`, and `async` functions without Babel, polyfills, or legacy-browser support. It is a desktop-only experience designed primarily for a 1920 by 1080 viewport, with 1280 by 720 as the minimum supported viewport; mobile layouts are deliberately out of scope.
